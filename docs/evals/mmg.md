# Evaluación de la regla de proceso — MMG

## 1. Tu predicción y el resultado obtenido

Mi predicción fue 80 % (4 de 5). Ese fue el resultado. La segunda ejecución no actualizó el README.

## 2. Qué harías con ese resultado

Convertiría la regla en una comprobación automática, pidiendo explícitamente que actualice el README.

## 3. Algo que tu medición no está comprobando

Usé siempre el mismo prompt con el mismo modelo. La única vez que no actualizó el archivo, la salida
fue diferente; las que sí lo actualizaron fueron similares entre sí. Creo que la vez que no funcionó
fue porque no actualizó ningún documento: esa corrida, la que falló, no tomó varias de las reglas. No
pude corroborarlo.
